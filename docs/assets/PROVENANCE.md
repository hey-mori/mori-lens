### 4. Smoke Test Assets (Structural CI Only)

**Smoke assets are placeholders for CI structural validation only. They are NOT used in release builds.**

#### Smoke Asset Generator
- **Script**: `scripts/generate-smoke-assets.py`
- **Purpose**: Generate minimal valid placeholder assets for CI packaging verification
- **Output**: Solid grey placeholders
- **Used by**: `.github/workflows/package-smoke.yml` (structural smoke test)
- **NOT used by**: `.github/workflows/release.yml` (real release)

**Important**: The release workflow must NEVER invoke the smoke asset generator. Release builds use only production assets.

### Distribution Rights

All distributed visual assets are generated by repository scripts, with no
third-party rights.

No third-party visual assets are distributed.

### Regeneration

**Production assets**:
```bash
python scripts/generate-product-assets.py
```

**Smoke assets** (for CI structural testing only):
```bash
python scripts/generate-smoke-assets.py
```

### Asset Pipeline Architecture

```
package-smoke.yml (CI structural test)
  → generate-smoke-assets.py (grey placeholders)
  → package with placeholders
  → upload as smoke test artifacts
  → NOT for distribution

release.yml (real release)
  → use existing production assets
  → NEVER invoke generate-smoke-assets.py
  → fail if production assets missing or invalid
  → package with production assets
  → suitable for distribution
```

### Customization

Production assets use a deterministic design (the Mori tile with a lens). To customize:
1. Modify design parameters in `scripts/generate-product-assets.py`
2. Regenerate all production assets
3. Commit updated assets

The design is simple, recognizable at small sizes, and appropriate for Windows tray/taskbar.

## Visual Quality Review

This document confirms asset **provenance** (origin and distribution rights). The design follows the Mori brand identity reference (`docs/design/mori-brand-identity-reference.md` in hey-mori/mori): the app icon is the rounded purple-gradient tile with the Mori star, and Lens adds the lens that says which product it is.

Review of 2026-11-05:
- Every ICO size from 16 to 256 px was compared on light and dark backgrounds. At 32 px and below the star read as a plus sign, so those sizes carry the lens alone.
- The tray glyph (`lens_core::icon`) is the same lens, a ring and handle in one colour, drawn at the size Windows asks for.
- `docs/assets/lens-mark.svg` renders the same drawing as `apps/lens/icons/icon.png`.
