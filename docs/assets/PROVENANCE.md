# Asset Provenance

This document traces the origin and distribution rights for all visual assets in the Mori Lens repository.

## Mark Assets (docs/assets/)

### docs/assets/mark.png
- **Purpose**: Repository mark displayed in README at 96×96
- **Origin**: Generated by the organization's mark generator
- **Source specification**: [swarea/.github/docs/repository-mark.md](https://github.com/swarea/.github/blob/main/docs/repository-mark.md)
- **Creator/rightsholder**: Organization (swarea)
- **Generated**: Yes, from mark-source.png
- **Generator**: Organization mark generator (external to this repository)
- **Source asset**: docs/assets/mark-source.png
- **Where used**: README.md header
- **Ships**: No (documentation only)
- **Distribution right**: Organization grant for repository use

### docs/assets/mark-source.png
- **Purpose**: Source card from which mark.png is cut
- **Origin**: Captured from organization mark generator output
- **Creator/rightsholder**: Organization (swarea)
- **Generated**: No (captured source)
- **Where used**: Kept for reproducibility of mark.png
- **Ships**: No (source asset)
- **Distribution right**: Organization grant for repository maintenance

## Summary

### Asset Categories

1. **Organization mark assets** (docs/assets/)
   - Source: Organization mark generator
   - Rights: Organization grant
   - Ships: No (documentation only)

2. **Application icon smoke assets** (apps/lens/icons/)
   - Source: Procedurally generated by repository script
   - Rights: No third-party rights (generated by script)
   - Ships: Yes (placeholder icons in distributed application)
   - Note: These are structural test assets, not production design

3. **MSIX packaging smoke assets** (packaging/windows-msix/Assets/)
   - Source: Procedurally generated by repository script
   - Rights: No third-party rights (generated by script)
   - Ships: Yes (placeholder logos in MSIX package)

### Distribution Rights

All distributed visual assets are either:
- Generated by repository scripts (no third-party rights), or
- Organization-provided with distribution grant

No third-party visual assets are distributed.

### Regeneration

All generated assets can be regenerated by running:
```bash
python scripts/generate-smoke-assets.py
```

This produces minimal valid placeholder assets suitable for packaging pipeline validation.

### Production Assets

For public release, the placeholder smoke assets would be replaced with production-designed icons. The current assets are sufficient for structural validation but not for end-user distribution.
